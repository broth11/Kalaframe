# Kalaframe MVP Roadmap

## MVP Complete

This package implements the planned MVP:
- Teacher form
- Directions
- Sub-timers
- Confirmation modal
- Timestamp timer
- Projector display
- BroadcastChannel + localStorage sync
- p5 visualizer registry with Dots, Lava Lamp, Aurora, Geometric Waves, and Void
- local preferences
- IndexedDB history

## Recommended Next Work

1. Test in real classroom projection conditions.
2. Test all visual themes in real classroom projection conditions.
3. Refine visual quality only after timer and display behavior remain stable.
4. Consider code-splitting p5 visualizers if bundle size becomes a problem.
5. Add history delete/clear controls only if needed.
6. Add more modes only if teacher use reveals a need.

## Avoid

- Accounts
- Cloud sync
- Soundscapes
- QR joining
- Classroom agenda board
- Student responses
